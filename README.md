Frontend Code Samples

This repository contains selected frontend code samples prepared for my application to Alley’s User Experience (Front-end) Developer role.

The samples come from larger private projects and were chosen to show different parts of how I approach frontend development:

1. Aqueduct Carousel — responsive interface behavior using CSS and native browser APIs
2. Evarra Adaptive Workflows — user experience design through different interaction paths for different user needs
3. Springmint Bonding Status — transforming application data into a consistent frontend display model

Each folder includes a short explanation of what I wrote, why I built it that way, and why I selected it as a sample.

The code here is intentionally limited to the portions relevant to each example rather than exposing the full project repositories.
